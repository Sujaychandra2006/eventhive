# EventHive design notes

Warm campus desk. Paper, ink, honey, moss. One board for the event, the tasks, and the volunteers.

## Colour

- Paper background: #f6f1e7
- Surface cards: #fffaf3
- Ink: #1c1915
- Muted text: #6b645c
- Honey accent: #c9842a
- Moss progress: #5f7a4a
- Line: #e6dfd2

## Type

- Headings: Fraunces
- Body and UI: Outfit

## Screens to frame in Figma

1. Overview — four stats, Coming up list, Still loose panel
2. Events list
3. Event workspace — Board tab with To do / Doing / Done
4. Volunteers — shift rows with Confirm
5. Mobile overview with bottom tabs

## How to make the Figma file

1. Open figma.com and create a file named EventHive.
2. Make a desktop frame, 1440 × 900.
3. Screenshot the running app at localhost:8080 and paste each screen into a frame.
4. Name the frames Overview, Events, Board, Volunteers.
5. That file is the design proof. Open it in the expo.
